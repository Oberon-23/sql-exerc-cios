# SQL: exercícios resolvidos

Repositório de estudo de SQL (PostgreSQL), com exercícios resolvidos organizados por aula.

## Banco de treino

Cenário de service desk com duas tabelas: `analistas` e `chamados`.
O script `00-banco/schema_e_dados.sql` cria as tabelas e carrega 6 analistas e 20 chamados.

Para rodar sem instalar nada: abra o [db-fiddle.com](https://www.db-fiddle.com), escolha **PostgreSQL**, cole o script no painel de schema e escreva as consultas no painel da direita.
